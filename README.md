# Ateliê Lume — Demo V2

Site estático premium para apresentação comercial de arquitetura/interiores.

## Publicação rápida
1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta.
3. Na Vercel: Add New → Project → importe o repositório.
4. Framework Preset: **Other**.
5. Não é necessário Build Command.
6. Deploy.

## O que trocar para um cliente real
- Nome/identidade: `index.html`
- WhatsApp: procure por `5511999999999`
- E-mail: `ola@atelielume.com.br`
- Instagram/Pinterest/LinkedIn: links `#`
- Posts/projetos: links dos `.project-card`
- Endereço/Maps: iframe na seção `#contato`
- Fotos: substitua os SVGs em `/assets`
- Google Sheets: em `app.js`, preencha `GOOGLE_SHEETS_WEBHOOK_URL`
